# Domain Docs

This repository uses a single-context domain-documentation layout.

## Before exploring

Read:

- `CONTEXT.md` at the repository root, if it exists.
- Relevant ADRs under `docs/adr/`, if they exist.

If these files do not exist, proceed without creating them automatically.

## Vocabulary

Use the domain vocabulary defined by `CONTEXT.md` when it exists. If a term is not defined, use the terminology already established by the application.

## ADR conflicts

If proposed work conflicts with an existing ADR, identify the conflict explicitly instead of silently overriding it.
